# Web-Installer

Folgt in Phase 5. Eine einzelne Datei `install.php`, die eine Kompanie über den Dateimanager ihres Hosters oder per FTP hochlädt und im Browser öffnet: Sie prüft die Voraussetzungen, erkennt WordPress, lädt das signierte Release der Kompanie und startet den Einrichtungsassistenten. Siehe [Architektur, Abschnitt 12](../docs/ARCHITEKTUR.md#12-installation-und-einrichtung).
