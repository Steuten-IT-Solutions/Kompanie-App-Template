titel: Manage internal calendar

Here you create, change and delete the events of the internal calendar of {kompanie.name}. Only logged-in people with the internal calendar see these events, e.g. {rolle.member} accounts and candidates. They are separate from the public events: guests don’t see what you enter here, and public events don’t appear here.

The page only exists if an admin has chosen the source **Maintain in the app** under **Settings** → **Calendar**.

## How to open this page
Tap **{bereich.events}** at the bottom and then **Manage internal calendar** at the top.

## What you see here
- **‹ To the events**: back to **{bereich.events}**.
- **+ Add internal event**: opens the form for a new event.
- **Upcoming in the internal calendar**: all upcoming internal events with date, time and location, each with **Edit** and **Delete**.

## Step by step
### Add an event
1. Tap **+ Add internal event**.
2. Enter **Title** and **Date**. Both are required.
3. If the event lasts several days, enter the last day under **Until (optional)**.
4. If needed, enter **Start (optional)** and **End (optional)**. Without a time the event counts as all-day. An end also needs a start.
5. If accepting and declining should end earlier than the start, enter a **Response deadline (optional)**. The field only exists if accepting and declining is switched on. Replies are then possible until the end of that day. It must not be after the date of the event.
6. Add **Location**, **Description** and a **Link (optional)** if you like. The link must start with http:// or https://.
7. Tap **Save**. “Event created” appears.

### Change an event
1. Tap **Edit** next to the event. The **Edit event** form opens at the top.
2. Change the details.
3. Tap **Save**. **Cancel** leaves everything as it was.

### Enter an event in English too
If the admin has switched on English under **Settings → Languages**, an admin enters the title, location and description in English there, in the **Translations** section in the **Upcoming events in the internal calendar** group. The form only shows a note with a link to it. The group shows events from today on; past ones drop out.

Those using the app in English see the event in this version, including in the notification. Anything left empty appears in German, with the note *Partly only available in German* on the opened event. Date, time and link apply to all languages. In this form you always edit the German version, even if you use the app in English yourself.

### Delete an event
1. Tap **Delete** next to the event.
2. Confirm. The event is gone immediately.

## Good to know
- Each event is a single event. Recurring events (e.g. every first Tuesday) you create one by one.
- Past events disappear from the list by themselves. For attendance lists the events of the last weeks remain available, as do all upcoming ones.
- Those who have switched on notifications for {bereich.events} and see the internal calendar get “{bereich.events}: new” for a new event. If you later change date, time or location, “{bereich.events}: changed” follows. The day before, the app reminds them of tomorrow’s events if this is switched on.
- For every event, everyone with the permission can accept or decline. Who answered how you see under **{bereich.events}** in the opened event with **View replies**, see [Accept or decline events](seite:zu-und-absagen).
- If an admin later chooses another source, the events stay stored here. They reappear as soon as the source is **Maintain in the app** again.
