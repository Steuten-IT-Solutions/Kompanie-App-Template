Here you see what has changed from version to version of the app, up to the version installed for you.

![The What’s new page](bild:admin-neuerungen)

## How to open this page
Tap **Admin** at the bottom, then **Settings** and **What’s new**. You can also reach it via the **What’s new** link under **Status and updates** next to the installed version.

## What you see here
- **Version …**: one section per version with date, number of changes and the changes, newest at the top. The installed version carries the label **installed** and is expanded; older versions are collapsed and open when tapped. If a pre-release is running, all versions below it are collapsed.
- **Pre-release** with the label **not yet released to everyone**: at the very top if a pre-release is running for you (see [Status and updates](seite:admin-zustand)). It lists what is already included there but has not been released to everyone yet.

## Good to know
- If a change mentions a path such as **Settings → Roles**, it is a link: tapping it opens the page where you set up the new feature straight away.
- The list belongs to the installed version and is available even without an internet connection. After an update the new entries are added.
- The list itself is written in German.
