---
titel: Set event types
---
Each event in the internal calendar can have one or more event types, e.g. **Meeting** or **Meeting** and **Work duty** together. This works with every source, including events from Google Calendar or an iCal address. The app stores the types itself and changes nothing in Google Calendar. Attendance lists take over the types of their event.

## How to open this page
Tap **{bereich.events}** at the bottom and then an event to open it.

## What you see here
- **Event types ›**: in the opened event, below it the chosen types (or **none**). Tapping it opens the ticks: one per event type, with all the types an {rolle.admin} has set up under **Settings** → **Calendar**. You can tick several. Another tap closes them again. All this only appears if there is at least one event type.
- **Suggested from the title: …** with **Apply**: if the name of an event type appears as a separate word in the title (e.g. “Meeting March”), the app suggests it, and all matching ones if there are several (e.g. “Meeting with work duty”). The suggestion only counts once you apply it.
- Each chosen type appears as a small label next to the title for everyone who sees the event. An {rolle.admin} can switch this off per type under **Settings** → **Calendar** (tick **Show as a label on the event**); the type is still stored.

## Step by step
### Choose event types
1. Open the event.
2. Tap **Event types ›** to open the ticks.
3. Tick every matching type. Each tick is saved immediately.
4. If there is a suggestion, one tap on **Apply** is enough (even when closed).

### Remove an event type
1. Tap **Event types ›** and remove the type’s tick. Without a tick the event has no type.

## Good to know
- If the event already has an attendance list, it gets the new types straight away.
- An event with several types counts for each, e.g. for the requirements for admitting candidates.
- Past events are no longer listed here. You change their type on the event’s attendance list if you may manage attendance.
- If an {rolle.admin} removes an event type from the list, events and lists keep it. It stays visible as ticked until you remove the tick; it can’t be chosen again afterwards.
