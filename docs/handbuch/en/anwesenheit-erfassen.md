Here you create an attendance list for each event and find the previous lists again. In the list you then enter who was present, excused or absent. For upcoming events you can already enter in advance who is excused.

![The {bereich.attendance} overview with calendar, other occasion and the recent lists](bild:anwesenheit-erfassen)

## How to open this page
Tap **Admin** at the bottom and then the **{bereich.attendance}** button.

## What you see here
- **Today**: today’s events from the {bereich.calendar}, even if they have already started or are over. The section only exists if something is on today.
- **Upcoming events**: the events from the {bereich.calendar} after today, the next one at the top. **Show more upcoming events** shows more than the first eight. If there are none, it says “Nothing coming up in the calendar.”
- **Past events**: the events from the {bereich.calendar} of the last 90 days up to yesterday, the most recent at the top. **Show older events** shows more than the first eight. If there are none, it says “Nothing took place in the last 90 days.”
- **List exists** on an event means: there is already a list for it.
- **Other occasion**: for anything not in the {bereich.calendar}, e.g. a spontaneous work duty.
- **Recent lists**: the previous lists with date, event types (if set) and counters, e.g. “3 present · 0 excused · 1 absent”. For events from the {bereich.calendar} the event types also appear after the time.

## Step by step
### Create a list for an event from the {bereich.calendar}
1. Under **Today**, **Upcoming events** or **Past events**, tap the event.
2. The list opens. If there already was one, the existing one opens.

### Create a list for another occasion
1. Under **Other occasion**, enter the **Title**.
2. Choose the **Date**. Today is preset.
3. Tap **Create list**.

![The form for another occasion, filled in](bild:anwesenheit-erfassen-frei)

### Open an existing list
1. Under **Recent lists**, tap the list.

How to enter in the list is described under [Attendance list](seite:anwesenheitsliste).

## Good to know
- The **Today**, **Upcoming events** and **Past events** sections only exist if the {bereich.calendar} is switched on. Events only appear there if the {bereich.calendar} is set up.
- For an upcoming event you can only enter **excused** until the day of the event. This also applies to another occasion with a date in the future. More on this under [Attendance list](seite:anwesenheitsliste).
- Title and date are saved with the list. So the list is kept even if the event is later moved or deleted in the {bereich.calendar}.
- There is at most one list per event from the {bereich.calendar}. You can create as many other occasions as you like.
- **Recent lists** shows the 50 newest lists.
- Everyone allowed to maintain {bereich.attendance} sees and edits the same lists.
- **View only:** with the permission **{bereich.attendance}: see lists per event and the {bereich.attendance} of members** but without **{bereich.attendance}: keep lists per event**, the events from the {bereich.calendar} and **Other occasion** are missing; you only see **Recent lists** and open them for viewing.
