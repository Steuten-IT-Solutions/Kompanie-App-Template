Under **{bereich.events}** you see the upcoming public events of {kompanie.name}, sorted by month. Everyone can see these events, even without logging in. You can add an event to your own calendar or get notified about new events.

![List of public events, sorted by month](bild:termine-und-kalender)

## How to open this page
Tap **{bereich.events}** at the bottom. This is usually also the app’s start page.

> If you are logged in and {kompanie.name} also uses its internal calendar, you see all events from that calendar here instead, including the internal ones. That is described on the help page **{bereich.events} with calendar**, which you then reach via **?**.

## What you see here
- **Month heading**: e.g. “October 2026”; below it that month’s events.
- **Event**: the date on the left; on the right the title, weekday and time and, if given, the location. If the event isn’t in the current year, the year is shown too. If there is no time, the event lasts all day.
- **Notify me about new events** (below the list, only when not logged in): takes you to the notifications.
- **Only available in German**: the event has no English version yet, so you see the German one.

## Step by step
### View an event
1. Tap the event. It expands and shows the description, if there is one.
2. If you like, tap one of the buttons below it (see below).
3. Tap the event again to collapse it.

![Expanded event with description and the “Add to my calendar” and “Map” buttons](bild:termine-und-kalender-termin)

The buttons of an expanded event:
- **Add to my calendar**: the app downloads a calendar file. Open it, and your phone or computer offers to add the event to your own calendar.
- **More info**: opens a web page about the event. The button only appears if a link has been entered for the event.
- **Map**: shows the location in a maps app: on Android you choose the app (e.g. Google Maps or Waze), on iPhone and Mac Apple Maps opens, on a PC Google Maps. The button only appears if a location is given.

### Get notified about new events
1. Below the list, tap **Notify me about new events**.
2. Choose what you would like to be notified about and tap **Switch on notifications**.

If you are logged in, you set this up under **My area** → **Account** → **Set up notifications**. Everything else is under [Notifications](seite:benachrichtigungen).

## Good to know
- Past events disappear from the list by themselves. An event lasting several days stays until its last day.
- If there are no upcoming events, the page says “Nothing coming up at the moment.”
- The public events are entered by whoever is responsible for them at {kompanie.name}. If an event is missing, contact the people in charge.
