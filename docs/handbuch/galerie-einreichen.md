Hast du schöne Bilder von einem Fest, reichst du sie hier für ein Album der {bereich.gallery} ein. Sie erscheinen erst, wenn jemand mit dem Recht zum Prüfen sie freigibt.

## So öffnest du die Seite
Tippe unten auf **{bereich.gallery}** und oben auf **Bilder einreichen**. Mit **‹ Alle Alben** kommst du zurück.

## Was du hier siehst
- **Album**: in welches Album die Bilder sollen.
- **Bilder**: eine oder mehrere Dateien als JPG, PNG oder WebP.
- **Einverständnis**: Du bestätigst, dass du die Rechte an den Bildern hast und die erkennbaren Personen einverstanden sind. Ohne Haken lässt sich nichts einreichen.
- **Deine Einreichungen**: jedes Bild mit Album und Stand: *wartet auf Freigabe*, *freigegeben* oder *nicht freigegeben* mit dem Grund.

## So gehst du vor
### Bilder einreichen
1. Wähle das **Album**.
2. Wähle unter **Bilder** die Dateien aus.
3. Setze den Haken beim Einverständnis.
4. Tippe auf **Einreichen**. Die App lädt die Bilder nacheinander hoch und zeigt, wie weit sie ist.

### Eine Einreichung zurückziehen
Solange ein Bild auf die Freigabe wartet, tippst du daneben auf **Zurückziehen** und bestätigst. Das Bild wird gelöscht.

## Gut zu wissen
- Der Server entfernt beim Einreichen Metadaten wie den Aufnahmeort und speichert das Bild höchstens so groß wie die übrigen Bilder der {bereich.gallery}.
- Wer prüft, bekommt eine Benachrichtigung, wenn du Bilder einreichst. Du bekommst eine, sobald ein Bild freigegeben oder abgelehnt ist (unter **Meins → Benachrichtigungen** einstellbar).
- Abgelehnte Bilder löscht der Server sofort; der Grund bleibt hier stehen.
- Offene Einreichungen bleiben, bis jemand sie bearbeitet. Wird dein Konto gelöscht, verschwinden sie; schon freigegebene Bilder bleiben ohne deinen Namen in der {bereich.gallery}.
