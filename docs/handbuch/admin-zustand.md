Unter **Konto → Einstellungen → Zustand der App** zeigt eine Ampel, ob alles läuft: Updates, {bereich.gallery}, {bereich.calendar}, Datensicherung und Server (PHP, Datenbank, freier Speicherplatz), ohne WordPress zusätzlich die Hintergrundaufgaben und der Schutz der Daten.

- **Grün**: alles in Ordnung.
- **Gelb**: etwas sollte erledigt werden, z. B. eine neue Datensicherung.
- **Rot**: etwas funktioniert nicht; der Text sagt, was zu tun ist.
- **Grau**: nicht eingerichtet bzw. in dieser Installation nicht verfügbar.

## Statusmeldungen an uns
Wenn ihr zustimmt, schickt die App einmal täglich eine kurze Statusmeldung an die Betreuer der App (Version und Ampel, ohne Namen oder Inhalte), damit sie Probleme früh sehen. Die Zustimmung lässt sich jederzeit zurücknehmen.
