## Updates
Neue Versionen kommen automatisch, solange **Updates automatisch einspielen (empfohlen)** eingeschaltet ist. Ausnahmen: Eine neue Hauptversion spielt die App nur ein, wenn du sie bestätigst, und mit WordPress kann die Webseite automatische Updates sperren; dann spielst du sie hier per Klick ein. Unter **Konto → Einstellungen → Updates** siehst du die installierte Version und kannst ein Update sofort einspielen. Schlägt ein Update fehl, bleibt die bisherige Version. Unter **Auf eine ältere Version zurück** wählst du eine frühere Version derselben Hauptversion; hinter eine neue Hauptversion zurück geht es nicht per Klick, sondern nur mit Hilfe der Betreuer.

## Datensicherung
Unter **Einstellungen → Datensicherung** lädst du eine Sicherung aller App-Daten und Einstellungen herunter. Bewahre sie an einem sicheren Ort auf: Sie enthält die Daten der Mitglieder. Die Ampel wird gelb, wenn noch nie eine Sicherung heruntergeladen wurde oder die letzte älter als 90 Tage ist.

Wiederherstellen: Mit WordPress nur auf derselben Webseite. Ohne WordPress auch auf einer neuen Installation (z. B. beim Umzug), aber nicht aus einer Sicherung des WordPress-Plugins.
