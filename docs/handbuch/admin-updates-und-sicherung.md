## Updates
Neue Versionen kommen automatisch. Unter **Konto → Einstellungen → Updates** siehst du die installierte Version und kannst ein Update sofort einspielen. Schlägt ein Update fehl, bleibt die bisherige Version. Mit **Zurückrollen** kehrst du auf die vorherige Version zurück.

## Datensicherung
Unter **Einstellungen → Datensicherung** lädst du eine Sicherung aller App-Daten und Einstellungen herunter. Bewahre sie an einem sicheren Ort auf: Sie enthält die Daten der Mitglieder. Die Ampel wird gelb, wenn die letzte Sicherung lange her ist.

Wiederherstellen geht nur auf derselben Installation bzw. Webseite.
