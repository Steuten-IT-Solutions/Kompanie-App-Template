# Begriffe Deutsch → Englisch

Feste Übersetzungen für die Kataloge (`packages/core/src/I18n/en.json`), damit dieselben Wörter überall gleich
heißen. Britische Schreibweise (colour, organise, cancelled). Die App spricht Nutzer mit „you“ an, kurz und freundlich
wie das deutsche „du“. Knöpfe im Imperativ („Save“, „Delete“), ohne Punkt.
